Правила стратегии Z-Score

СТАТИСТИЧЕСКИЙ ВХОД (Z-Score ≥ 3.5)

1Статистический триггер: |Z| ≥ 3.5 (отклонение от 24ч EMA на 3.5 сигмы). Рассчитывается в реалтайме по WebSocket и минутным барам.
2Направление: Z > 0 → шорт дорогой биржи, лонг дешевой; Z < 0 → лонг дешевой, шорт дорогой.
3Анти-рассинхрон: разница возраста котировок ног ≤ 7.0 с (поддержка REST-опроса BingX), отсечка битых спредов > 3%.
4Честный VWAP по стакану L2: покупка и продажа моделируются проходом по реальным уровням книги заявок.
5Маржа безопасности: реальный спред по VWAP обязан быть больше 4 тейкерских комиссий + 0.10% чистой прибыли.

ВЫХОД И ЗАКРЫТИЕ ПОЗИЦИИ

  • Схождение (converged): Z-Score возвращается к 0.0 И расчетный PnL закрытия по реальным стаканам с учетом всех комиссий ≥ 0.
  • Тайм-стоп (timestop): если схождение не произошло за 30 минут (1800 с) → закрытие по рынку для ликвидации временного риска.
  • Стоп-лосс (stop): расширение аномалии до |Z| ≥ 7.0 (2 × entry_z) → экстренный выход.
  • Максимальное удержание: принудительный выход через 72 часа.

УЧЕТ ИЗДЕРЖЕК В ЭМУЛЯТОРЕ

  • Комиссии: списываются 4 × taker (вход обеих ног + выход обеих ног).
  • Проскальзывание: реальный VWAP по глубине 20 уровней стакана.
  • Фандинг: точный календарный учет по временным меткам начислений.

Все параметры настраиваются в config.yaml в блоке zscore.
