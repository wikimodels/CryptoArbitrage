Правила входа / выхода

ВХОД — общий конвейер (все 12 шагов должны пройти)

1Монета на ≥ 2 биржах (каталог, фильтры исключений)
2Котировки свежие (≤ 6 с), стакан не перекрёстный (bid < ask)
3Медиана цен: одноимённые разные токены отбрасываются (отклонение > 50%)
4Ноги по времени: Δt котировок ≤ 2 с (анти-фантом)
5Сырой спред ≤ 3% — выше считается битой котировкой
6Ликвидность вершины книги ≥ $200
7Динамический размер: 10% × топ-3 уровня худшей ноги, [10..1000] USDT. < $10 → сделки нет (стакан не двигаем)
8net_edge ≥ 0.30% = спред + funding − комиссии (4×taker) − slippage (глубина+буфер) − ширина обеих книг
9Funding не главный: funding_edge ≤ 15% спреда (иначе спред = вшитый funding и не сойдётся)
10Спред существует на реальном стакане прямо сейчас: (bid_шорт − ask_лонг)/ask_лонг ≥ 0.30%
11Кулдауны: 60 с после любого закрытия пары; 15 мин после убыточного
12Orphan-leg: обе ноги должны исполниться по реальной глубине, иначе отмена

Сплит стратегий — по входному спреду

ARBСпред ≥ 1% — жирный, ждём схождения
SCALPСпред < 1% — мелькающий lead-lag, быстрая сделка

ВЫХОД — SCALP (красный бейдж)

  • Спред сжался до 30% от входного → закрытие (забираем схождение)
  • 90 секунд не сжался → тайм-стоп (дальше — направленный риск)
  • Funding на таком горизонте ≈ 0 (учитывается дискретно по календарю)

ВЫХОД — ARB (зелёный бейдж)

  • net_edge упал до ≤ 0.15% (порог × 0.5) → спред сошёлся, закрытие
  • 72 часа → принудительное закрытие (max holding)

Общее для выходов

  • Выход идёт по реальной глубине стакана (как вход). Нет ликвидности на объём → закрытие откладывается, позиция остаётся открытой (событие exit_no_liquidity)
  • Funding считается дискретно по фактическим датам начислений (next_funding_ts на входе) — держал 7.9ч из 8ч интервала = 0 платежей

Экономика скальпа — почему не каждая монета берётся

  • Полный цикл = 2 ноги × (вход + выход) = 4 × taker ≈ 0.24% комиссий
  • + slippage и ширина книг ≈ 0.06% → кост-флор ≈ 0.30%
  • Средний захват монеты (из статистики) должен быть выше 0.30% — иначе после комиссий минус
  • Пример из данных: UNITREE захват 0.48% → нетто +0.24% (берём); TRUMP 0.21% → нетто −0.03% (не берём)

Учтённые издержки

  • Комиссии: 4 × taker (вход+выход × обе ноги)
  • Slippage: проход по глубине стакана на объём + буфер 0.02%
  • Ширина книг: полная ширина bid-ask обеих бирж (платим при выходе даже без движения цены)

Все пороги — в config.yaml. События отказов видны во вкладке «События» (SKIP: причина).
